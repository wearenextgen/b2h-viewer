# B2H stable homepage and viewer links

These are the permanent public URLs already intended for website embeds. Do not
rename the HTML files or create replacement URLs. Updated geometry must overwrite
the existing GLB filename used by the relevant viewer and by `homepage.js`.

## Homepage

- <https://wearenextgen.github.io/b2h-viewer/>

The homepage imports the same GLB filenames used by the individual viewers. It is
a scroll-controlled presentation, not an iframe or manually controlled viewer.
